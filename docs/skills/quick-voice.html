5שלבי התקנה

  1. הורידו את הסקיל

    curl -L https://aviz85.github.io/claude-skills-library/downloads/quick-voice.zip -o /tmp/quick-voice.zip unzip /tmp/quick-voice.zip -d ~/.claude/skills/
  2. הגדירו את ה-API Key
    cd ~/.claude/skills/quick-voice cp .env.example .env # ערכו את הקובץ ושימו את המפתח שלכם: # OPENAI_API_KEY=sk-...
  3. זהו, מוכן

    ה-launcher יתקין אוטומטית את התלויות (express, dotenv) בהפעלה הראשונה.

🔑

צריך OpenAI API Key עם גישה ל-Realtime API. אם המפתח לא מורשה — תקבלו שגיאת SDP בדפדפן.

6איך השיחה רצה בפועל

1. אומרים לקלוד

״תפעיל איתי שיחה קולית על [נושא]״ — או שקלוד מסיק מההקשר של השיחה הנוכחית.

2. קלוד מייצר session

יוצר runtime/<id>/config.json עם הוראות בעברית, מצב (live/distill), רשימת כלים מותרת ורמזי קנבס.

3. ה-launcher עולה

node scripts/launch.js <id> — מוצא פורט פנוי בטווח 3031-3040, מעלה שרת, ופותח דפדפן.

4. מדברים

WebRTC ישיר מהדפדפן ל-OpenAI. הקנבס והכלים פעילים. הסוכן עובד בזמן אמת.

5. סוגרים

סגירת דפדפן / לחיצה על ✓ / קריאת end_session — והסקיל מחזיר את output.md לקלוד.

7דוגמת קונפיג

״בוא נעבור על התמונות שיצרת״ (distill + קנבס תמונות):

{ "mode": "distill", "topic": "סקירת תמונות", "instructions": "הצג כל תמונה ב-canvas_show, שאל 'מה דעתך?', שמור פידבק ב-save_note. בסוף end_session.", "voice": "ash", "tools": ["canvas_show", "canvas_clear", "save_note", "end_session"], "canvas_hints": [ { "type": "image", "source": "/abs/path/img-1.png", "title": "1" }, { "type": "image", "source": "/abs/path/img-2.png", "title": "2" } ], "output_template": "# פידבק על תמונות\n\n" }

9אנטי-פטרנים — דברים שלא לעשות

  • ❌ אל תטמיעו את ה-OPENAI_API_KEY ב-config או ב-HTML — תמיד מ-.env
  • ❌ אל תכתבו instructions ארוכים — מעל 2KB הסוכן מאבד מיקוד
  • ❌ אל תפעילו file tools בלי cwd — בלי scope, ה-blast radius גדול מדי
  • ❌ אל תפעילו run_bash אלא אם חייבים — תעדיפו כלים ספציפיים
  • ❌ אל תמחקו אוטומטית את runtime/<id>/ — לפעמים רוצים לחזור אליו

10פתרון בעיות

"Server did not become ready in 8s"

בדקו את runtime/<id>/server.log. בדרך כלל זה OPENAI_API_KEY שגוי או תלות חסרה.

הדפדפן לא נפתח

ה-launcher מדפיס את ה-URL לקונסול. פתחו ידנית.

שגיאת SDP מ-OpenAI

החשבון שלכם לא מורשה ל-Realtime API. בדקו ב-platform.openai.com שיש הרשאה.

כלים מחזירים שגיאות

פתחו DevTools בדפדפן ובדקו את ה-Console. את הצד-שרת תמצאו ב-server.log של ה-session.
