💡 מה זה בכלל?

מה זה Skills?

Skills הם כמו "תוספים" לקלוד קוד. הם מלמדים אותו לעשות דברים חדשים שהוא לא יודע לעשות מהקופסה.

🧠

ידע מיוחד

כל Skill מכיל הוראות מפורטות שמלמדות את קלוד איך לבצע משימה ספציפית בצורה הטובה ביותר.

🔧

כלים מוכנים

סקריפטים וקוד מוכן מראש שקלוד יכול להשתמש בהם בלי שתצטרכו לכתוב אותם בעצמכם.

⚡

פעולה אוטומטית

קלוד מזהה אוטומטית מתי להשתמש בכל Skill לפי מה שאתם מבקשים ממנו - בלי צורך בפקודות מיוחדות.

🖱️ קליק ימני על תיקייה (Windows)

רוצים לפתוח תיקייה ב-Claude Code בקליק ימני? פשוט בקשו מקלוד:

"הוסף לתפריט קליק ימני אפשרות לפתוח תיקייה ב-Claude Code"

קלוד יוסיף לרגיסטרי של Windows שתי אפשרויות:

  • Open in Claude Code - פתיחה רגילה
  • Open in Claude Code (No Limits) - מצב ללא מעצורים

💡 בקשו שיוסיף גם "הפעל כמנהל" לאפשרות השנייה

⚡ מצב ללא מעצורים

claude --dangerously-skip-permissions

מה זה? מצב שבו קלוד לא מבקש אישור לפני כל פעולה - הוא פשוט עושה.

מתי להשתמש: כשאתם בטוחים במה שאתם עושים ורוצים לחסוך את ה"האם לאפשר?" על כל פעולה.

⚠️ זהירות: השתמשו רק בפרויקטים שאתם מכירים. קלוד יכול למחוק/לשנות קבצים בלי לשאול.

🎬 פקודת /init

/init

פקודת /init מאתחלת פרויקט חדש. קלוד יסרוק את התיקייה, יזהה את סוג הפרויקט, וייצור קובץ CLAUDE.md מותאם.

הקובץ הזה מלמד את קלוד איך לעבוד עם הפרויקט שלכם - איזה פקודות להריץ, מה חשוב לדעת, ואיזה כללים לעקוב.

🎯 איך מתחילים פרויקט אג'נטי?

בפלאגין שלנו יש סקיל find-my-project שעוזר לכם למצוא את הפרויקט הראשון שלכם.

  1. הסקיל שואל 3 שאלות על הכאבים היומיומיים שלכם
  2. מנתח ומציע רעיונות לאוטומציה
  3. מסתיים באפיון מערכת מפורט
  4. אחרי שמקבלים אפיון - מבקשים מקלוד "לממש את האפיון"

💡 הסקיל משתמש גם ב-gmail לבדיקת דפוסים במיילים שלכם (אם הותקן)

התשובות לשאלות הנפוצות ביותר

האם זה בחינם?

כן! הספרייה היא קוד פתוח ובחינם לשימוש. חלק מהסקילים דורשים חשבונות חיצוניים (כמו Green API או ElevenLabs) שעשויים להיות בתשלום.

מה זה קלוד קוד?

Claude Code הוא כלי שורת פקודה רשמי של Anthropic שמאפשר לעבוד עם קלוד ישירות מהטרמינל. הוא יכול לקרוא ולערוך קבצים, להריץ פקודות ולבצע משימות מורכבות.

איך אני יודע איזה Skill להשתמש?

פשוט תבקשו מקלוד מה שאתם צריכים! הוא מזהה אוטומטית איזה Skill מתאים. למשל, אם תכתבו "שלח הודעה בוואטסאפ" - הוא ישתמש ב-whatsapp skill.

אפשר ליצור סקילים משלי?

בהחלט! השתמשו ב-skill-creator שבספרייה. הוא מדריך אתכם צעד אחר צעד ביצירת סקילים חדשים עם כל מה שצריך - תבניות, דוגמאות ושיטות עבודה מומלצות.

⚡ טיפ חשוב: לפני שקלוד כותב סקיל, בקשו ממנו: "תשאל את claude code guide מה הפורמט הנכון לסקיל" - זה מבטיח שהסקיל יהיה בפורמט הנכון והעדכני.

האם זה בטוח?

הקוד הוא קוד פתוח ואפשר לעיין בו. אף פעם אל תכניסו מפתחות API או סיסמאות לקבצים שאתם משתפים. השתמשו בקבצי .env לאחסון מידע רגיש.

מה מבנה הקבצים בכל סקיל?

כל סקיל מכיל שני קבצים עיקריים:
skill.md - הקובץ הראשי שמלמד את קלוד איך להשתמש בסקיל (קצר וממוקד).
SETUP.md - מדריך הגדרה מפורט (נקרא רק כשצריך עזרה בהתקנה).
ההפרדה הזו חוסכת "זיכרון" לקלוד ומאפשרת תגובות מהירות יותר.
